# Background Vocal Session Recipe

## Goal

Adapt the generated chain logic for doubles, harmonies, and background vocals while preserving separation from the lead.

## Session Recipe

1. Start from the lead-vocal style direction.
2. Reduce intensity if the background part should sit behind the lead.
3. Generate the chain and export the settings.
4. Rebuild the chain on the supporting vocal bus or grouped tracks.
5. Narrow width, soften presence, or increase ambience as needed inside the DAW.

## Best Use Case

- doubles
- stacks
- harmony buses
- support vocal shaping
