# Lead Vocal Session Recipe

## Goal

Build a repeatable lead-vocal workflow that moves quickly from style intent to implemented chain.

## Session Recipe

1. Choose a preset or enter a style prompt.
2. Select the DAW for plugin-aware mapping.
3. Set the target intensity based on arrangement density.
4. Generate the chain.
5. Export the result as text or JSON for recall.
6. Rebuild the chain on the lead vocal track.
7. Adjust threshold, EQ gain, and ambience by ear to match the performer.

## Best Use Case

- lead vocal setup
- revision-heavy client sessions
- repeatable template building
